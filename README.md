# Curso: AI-DLC & SDLC na AWS com Kiro, Amazon Bedrock e Multi-Cloud

Curso técnico em HTML (página única, autocontida) sobre o **AI-Driven Development
Lifecycle (AI-DLC)** — a evolução do SDLC em que agentes de IA participam de cada
fase do ciclo de desenvolvimento, sob portões de aprovação humana e com
rastreabilidade ponta a ponta.

## 🌐 Curso online

Acesse a versão publicada via **GitHub Pages**:
👉 https://elbernardino.github.io/curso-ai-dlc/

## Conteúdo (10 módulos)

1. **SDLC clássico** — as fases e suas dores
2. **AI-DLC** — os 3 princípios (intenção→spec, humano no comando, rastreabilidade)
3. **Kiro** — desenvolvimento dirigido por specs (requirements/design/tasks, steering, hooks)
4. **Amazon Bedrock** — o motor de modelos (foundation models, knowledge bases, guardrails)
5. **Fluxo AI-DLC ponta a ponta** — raias humano ↔ agente e os portões de aprovação
6. **Arquitetura de referência** — as 5 camadas do pipeline
7. **Deploy multi-cloud** — estratégias e serviços equivalentes AWS · Azure · GCP
8. **Integrações** — a cadeia de rastreabilidade Kiro → Jira → Git → CI/CD
9. **Segurança, custo e governança** — guardrails, FinOps, humano no loop, auditoria
10. **Laboratório guiado** — roteiro do zero ao deploy + glossário

## Como usar localmente

Basta abrir o arquivo `index.html` em qualquer navegador. Não há dependências
externas nem build.

## Aviso

Os trechos de código são ilustrativos. Confirme a disponibilidade de serviços e
modelos por região antes de implementar em produção.
